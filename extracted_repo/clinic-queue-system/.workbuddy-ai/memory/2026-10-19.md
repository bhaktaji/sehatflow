# 2026-10-19 — Clinic queue system: full implementation and green test suite

## Delivered
- Backend (Spring Boot 3.3.5 / Java 21 / PostgreSQL 16): auth (cookie session + CSRF),
  multi-tenant queue, state machine, ETA, public patient/display views, SSE, audit,
  rate limiting, Flyway migration, seeded demo clinic.
- Frontend (React 18 + TS + Vite, port 5180): login, reception dashboard, doctor view,
  patient page, waiting-room display, offline banner, reason dialogs.
- Tests: 25 backend unit, 35 PostgreSQL integration, 7 frontend unit, 5 Playwright E2E — all green.
- Docs: README (setup, API, security, requirement coverage), scripts for test runs.

## Bugs found by tests (fixed)
- `TokenStatus.fromDb("CANCEL")` crashed session close → map resolution explicitly.
- `spring.mvc.problemdetails.enabled=true` swallowed the stable `code` extension → disabled.
- Axios client returned `AxiosResponse` instead of `.data` → API methods unwrapped.
- App never restored the session on reload → added `bootstrap()` + `initialized` gate.
- 401 from the `/auth/me` probe redirected public pages to /login → interceptor guards.
- CORS allowlist missed the dev port → Chromium's Origin header on POSTs caused 403.
- Malformed/`undefined` UUID path params returned 500 → `MethodArgumentTypeMismatchException` → 400.
- Unknown static paths returned 500 → `NoResourceFoundException` → 404.

## Environment gotchas (this machine)
- Shell `JAVA_HOME` points at JRE 8; scripts force JDK 21 (`/c/Program Files/Microsoft/jdk-21.0.12.101-hotspot`).
- PostgreSQL must run on port **5433** (`pg_ctl -o "-p 5433"`); it dies with the shell tree,
  so `scripts/ensure-postgres.sh` starts it inside the same command as the tests.
- Port 5173 is used by another project (gym-management) → clinic frontend uses 5180.
- `netstat` is unreliable here; kill stale dev servers via PowerShell CIM command-line filters.
- Multi-line `psql -c` args silently fail through cmd.exe → E2E helpers flatten SQL to one line.
