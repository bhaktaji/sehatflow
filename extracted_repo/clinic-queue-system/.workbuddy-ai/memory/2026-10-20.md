# 2026-10-20 — Windows launcher scripts for clinic-queue-system

## Added
- `start-all.bat` — one-click launcher (PostgreSQL → backend → Vite → browser),
  with `--rebuild`, `--no-build`, `--no-browser` switches.
- `stop-all.bat` — stops backend, frontend and the detached PostgreSQL cluster.
- README section "One-click launcher (Windows)".

## Machine facts the launcher encodes
- `java` on PATH and `JAVA_HOME` are **JRE 8** (`Eclipse Adoptium\jre-8.0.504.1-hotspot`);
  the real JDK 21 is `C:\Program Files\Microsoft\jdk-21.0.12.101-hotspot`.
  JDK detection = `bin\javac.exe` exists AND `javac -version` major >= 21.
- Maven **is** on PATH (`C:\Program Files (x86)\apache-maven-3.9.16\bin`), unlike the
  mall project where it had to be hunted down.
- PostgreSQL 16 binaries: `C:\Users\Aakash\pg16\bin`, data `...\data`, and it MUST be
  started with `-o "-p 5433"` (default is 5432).
- Ports: backend 8090, frontend 5180, DB 5433.

## Batch-script traps hit while building this (worth remembering)
- `for /f "tokens=2 delims=."` on `javac -version` yields "0" for `javac 21.0.12`
  — delims must be `". "` (dot + space).
- A quoted absolute path with spaces inside `for /f ('...')` is mis-parsed; run the
  tool from `pushd "%dir%\bin"` and call it by bare name instead.
- `timeout /t` resolves to GNU timeout under Git Bash (prints "invalid time interval")
  and Windows' timeout.exe refuses redirected stdin → use `ping -n N 127.0.0.1`.
- `else if (...)` chains and `%VAR%` set-and-read inside the same parenthesised block
  both break in cmd.exe → use labels and `!VAR!` (delayed expansion).
- Nested quotes in `start ... cmd /k "cmd "%path%" args"` are fragile → use a relative
  path from the working directory set by `/D`.
